Project 1

Simple E-commerce Store

Product catalogue, cart persisted per user, checkout and order history.

Node.js + Express SQLite JWT in httpOnly cookie bcrypt

What this task does

Log in with a demo account and open the app.

  • Product grid with text search, category filter and four sort orders
  • Product details page with stock status and a quantity picker
  • Cart stored in the database per user, so it follows you between browsers
  • Checkout that creates the order, reduces stock and clears the cart in one transaction
  • Order history with statuses, and cancel-with-restock
