How it is built

One Express server Routes mounted per module under /api
One SQLite file better-sqlite3, parameterized queries only
One auth system bcrypt + JWT in an httpOnly cookie
Socket.io namespaces /projects for boards, /meet for calls
WebRTC mesh Google STUN, Socket.io signalling
Web Crypto PBKDF2 key, AES-GCM chat and files
